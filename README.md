# Libra Library Management System

Libra is a high-fidelity, visually polished library management and personal reading companion application. Built using a sleek glassmorphic dark theme, the app offers a premium experience for students, educators, casual readers, and library administrators.

## 🌟 Key Features

- **Personal Reading Dashboard**: Monitor active checkouts, track custom reading progress, and keep motivated with detailed statistics.
- **Page-Based Reading Progress**: Update your progress book-by-book using direct page-number inputs rather than generic percentages. The system calculates completion dynamically relative to each book's actual page count.
- **My Shelf**: View checked out, completed, or favorite books in a unified space with specialized status filters.
- **AI Librarian**: Interact with an embedded conversational assistant powered by Gemini to receive personalized, smart reading recommendations and answer general literature queries.
- **Search & Discovery**: Browse, filter, and discover books across multiple genres with search queries and quick-filter category badges.
- **Admin View**: Manage catalog inventories, monitor overdue items, track active borrow records, and view system metrics.

## 🎨 Tech Stack & Visual Identity

- **Frontend Framework**: React 18+ with TypeScript and Vite.
- **Styling**: Tailwind CSS with custom glassmorphism and a warm, eye-safe slate palette.
- **Icons**: Lucide React.
- **Animations**: `motion` (Framer Motion).
- **AI Integration**: Server-side Google Gemini API integration.
- **Local Persistence**: Client-side localStorage synchronization to preserve your borrow history, favorites, and profile configurations.
